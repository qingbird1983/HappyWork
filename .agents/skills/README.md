# skills —— 可复用方法沉淀

- 一主题一文件，命名 `S-NNN-短slug.md`（三位递增编号），单篇 ≤ 120 行。
- 内容是"怎么做某类事"的可复用步骤，不是项目事实（事实归 docs/），也不是踩坑记录（归 pitfalls/）。
- vendored 第三方技能放**独立子目录**（如 `skills/<上游技能名>/`），须保留来源与许可证信息（SKILL.md frontmatter 的 `license` 字段 + 目录内 LICENSE 文件），不计入 .agents 预算、不修改其内容——上游更新时整体替换。
- 新增前先检索去重；方法被规范/ADR 吸收为正式规则后删除对应条目（vendored 技能除外，持续引用即可）。
