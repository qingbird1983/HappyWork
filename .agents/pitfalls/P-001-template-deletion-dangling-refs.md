# P-001-初始化删模板文件后残留引用悬空

## 现象

按 SETUP.md 初始化要求删除全部 `_TEMPLATE.md`、`ADR-0000-template.md`、`SETUP.md` 及占位目录后，部分文档仍引用被删对象：`roadmap/00-roadmap.md` 原写"阶段文档从 `_phase-template.md` 复制"、`.agents/README.md` §4 原写"同目录下有可直接复制的 `_TEMPLATE.md`"、standards/01 §1 目录树仍列已删的 `fixtures/`、`examples/`。

## 根因

模板体系是"文件 + 规则文本"两处维护：删除动作只处理了文件，没有同步处理散落在其他文档里的规则性引用。SETUP.md 的清理步骤（第 7 条）只说"删除"，没提示"全局检索引用"。

## 修复

删除后全局 `grep -rn "<被删文件名>"` 并逐处修正（本仓库 2026-10-30 已修：roadmap 措辞改为"命名规则"、.agents/README §4 改为内联模板、standards/01 目录树去掉已删目录并注明"启用时重建"）。

## 预防

任何"删除文件"类清理动作收尾时，把被删文件名（含去掉扩展名的形式）加入全局检索清单；模板/骨架类仓库初始化时，先 grep 引用再删文件。

## 归属

Phase 0 / 仓库初始化 / 无代码改动。
