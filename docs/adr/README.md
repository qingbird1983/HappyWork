# adr —— 架构决策记录（ADR）

## 是什么

ADR 记录**一次重大决策**的背景、决定、理由与后果——回答"为什么这么做"。它不是设计文档（设计在 `docs/architecture/` 与 `docs/design/`），只装决策本身。

## 规则

1. **命名**：`ADR-NNNN-短主题.md`，四位编号从 `0001` 递增（`ADR-0000-template.md` 是模板，初始化后删除）。
2. **只增不改**：定稿后的 ADR 不修改正文；推翻旧决策 = 写新 ADR 并在两篇头部注明"取代 / 被取代"关系。
3. **一篇一个决策**：单篇 ≤ 100 行；装不下说明决策该拆。
4. **何时必须写**：技术选型、范围排除/纳入、规范的规则级修改、任何"以后会有人问为什么"的取舍。拿不准就写——ADR 便宜，失忆昂贵。
5. **登记**：新增 ADR 必须同步 `docs/README.md` 清单表与 CHANGELOG。

## 状态流转

`草稿 → 定稿`（本项目 ADR 一般不走"评审中"，写完即定稿；被取代时标 `已被 ADR-NNNN 取代`）。
