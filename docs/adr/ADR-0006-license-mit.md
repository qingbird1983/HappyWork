# ADR-0006：项目许可证采用 MIT

- 状态：定稿
- 日期：2026-10-30
- 关联：SETUP.md 初始化步骤 3（许可证须所有者确认 + ADR）

## 背景

仓库初始化需确定许可证。所有者于 2026-10-30 在 MIT / Apache-2.0 / GPL-3.0 / 专有四选项中选定 **MIT**。

## 决策

1. 仓库整体采用 **MIT License**，全文替换 `LICENSE` 占位文件。
2. 版权主体：**The HappyWork Authors**（所有者可随时在 LICENSE 中改署名，属行政修订，不需新 ADR）。
3. vendored 内容（如 `.agents/skills/ponytail/`，MIT）保留其原始版权与许可声明。

## 理由

- 个人开源项目主流默认：宽松、简洁、无传染性，不阻碍未来任何商业化路径（可另行商业授权）。
- 备选 Apache-2.0：专利授权条款对当前单人项目收益有限，文本冗长。
- 备选 GPL-3.0：强传染性与"未来可能商用"保留冲突。
- 备选专有：与开源仓库模板的协作预设不符，所有者未选择。

## 后果

- 积极：任何人可自由使用/修改/再分发（保留声明）。
- 代价/义务：无专利授权条款（如需可日后改 Apache-2.0，写新 ADR 取代本篇）；接收外部贡献前建议加 CLA/贡献者协议。
- 重新评估条件：引入需要专利保护的组件，或转为商业许可分发。
